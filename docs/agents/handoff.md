# Handoff — журнал передачи работы

Живой журнал сессий работы ИИ-агентов. Цель — чтобы следующий агент или человек за минуту понял,
что сделано, что открыто, где ловушки и что делать дальше. Дополняет
[roadmap](../roadmap.md) (план) и [CHANGELOG](../../CHANGELOG.md) (изменения для пользователей):
здесь — состояние работы.

## Формат записи

Новая запись добавляется **сверху** (сразу после этого раздела), дата — `YYYY-MM-DD`:

```markdown
## YYYY-MM-DD — краткое название (2–5 слов)

- **Задача:** что требовалось.
- **Сделано:** что реально изменено (файлы/поведение).
- **Проверено:** какие команды запущены и результат.
- **Открыто:** что не сделано, известные риски, ловушки.
- **Следующий шаг:** конкретное действие для следующей сессии.
```

Правила:

- запись обязательна в конце каждой сессии, даже если работа не завершена;
- только факты и состояние — без пересказа диффа и без секретов;
- после добавления записи: `python3 scripts/doc_system.py touch docs/agents/handoff.md`;
- храни последние ~10 записей; более старые сворачивай в одну строку со ссылкой на
  CHANGELOG/ADR.
