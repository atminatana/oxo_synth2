# Поддержание документации (doc-system)

Документация проверяется и обновляется как код. Здесь описан механизм; правила для агента — в
[AGENTS.md](../../AGENTS.md), процесс — в [workflow.md](workflow.md).

## Принцип

1. **Манифест** [docs/docs.toml](../docs.toml) — единственный источник истины: список документов,
   обязательные разделы, влияние кода, дата/коммит/момент проверки.
2. **Runtime** [scripts/doc_system.py](../../scripts/doc_system.py) — проверяет инварианты,
   находит устаревшее, генерирует служебные фрагменты.
3. Служебные фрагменты **генерируются**, поэтому не расходятся с манифестом.
4. Проверка встроена в локальный шлюз проекта (`make docs-check`); git-хуков и CI в репозитории
   нет, поэтому отметку проверки сдвигает агент после осмысленного чтения документа.

## Манифест

| Поле | Смысл |
| --- | --- |
| `[[doc]] path` | путь от корня; файл обязан существовать; любой `.md` в `docs/**` должен быть в манифесте |
| `title`, `summary` | название и одна строка «о чём» для индекса `docs/README.md` |
| `sources` | glob-шаблоны кода/конфигов; изменение этих файлов делает документ потенциально устаревшим |
| `sections` | подстроки заголовков, которые обязаны быть в документе |
| `verified` | `{ commit, date, time }` — база и момент последней проверки; обновляется `touch` |
| `immutable` | `true` только для ADR: исторические записи не требуют повторной проверки |
| `[meta]` | пороги (`max_age_days`, `handoff_soft_days`), `root_coverage`, обязательные файлы, `system_version` |

`verified.commit = "none"` — база не зафиксирована: после первого коммита выполни
`touch --all`. Пока база не зафиксирована, полный `check` считает это ошибкой (CI не будет
зелёным). `touch` записывает `HEAD` (или `none`, если коммитов нет) и момент проверки
`verified.time`: проверка свежести понимает, что документ проверен после правок кода, даже если
они ещё не закоммичены.

`sources` описывает только код/конфиги. Не ссылайся на другие документы — иначе отметка одного
документа вызывает каскад ложных «устарел».

## Команды

```bash
python3 scripts/doc_system.py check      # проверка
python3 scripts/doc_system.py sync       # генерация
python3 scripts/doc_system.py stale      # устаревшее
python3 scripts/doc_system.py touch docs/architecture.md CHANGELOG.md
python3 scripts/doc_system.py touch --all   # baseline
python3 scripts/doc_system.py version    # версия runtime и манифеста
```

Что проверяет `check` (ошибки — ненулевой код возврата):

- манифест разбирается, обязательные поля/файлы на месте, пути уникальны и существуют;
- все `.md` в `docs/**` зарегистрированы (корневые — если включён `root_coverage`);
- в каждом документе есть обязательные разделы;
- футеры и индекс совпадают с манифестом;
- относительные ссылки ведут на файлы, якоря `file.md#раздел` — на заголовки (`.md`/`.mdc`);
- база проверки зафиксирована (иначе ошибка);
- устаревание и просроченный handoff — предупреждения; `--strict` делает их ошибками.

`check --fast` пропускает git-проверку (быстрый прогон без обращения к истории). `sync` сначала
строит полный план и только затем записывает — при ошибке дерево не остаётся частично
обновлённым.

## Политика актуальности

| Событие | Действие |
| --- | --- |
| Изменил код из `sources` | Перечитать документ, обновить, `touch` |
| Изменил документ | `touch` после `check` |
| Пользовательское поведение | `CHANGELOG.md` → `[Unreleased]` |
| Неочевидное решение | Новый ADR (immutable), ссылка из architecture/roadmap |
| Появился первый коммит | Один раз `touch --all` (baseline) |
| В handoff давно нет записей | Предупреждение через `handoff_soft_days` (30 дней) |
| Прошло 90 дней с проверки | Предупреждение; перечитать и `touch` |
| Документ больше не нужен | Удалить файл и запись манифеста, убрать ссылки; причина — в handoff/ADR |

Границы автоматики: скрипт не понимает смысл текста. Он гарантирует существование, полноту,
ссылки и свежесть отметок, но не истинность утверждений. Истинность обеспечивает агент, читая
документ при изменении `sources`; `touch` без чтения — нарушение контракта.

## Генерируемые фрагменты

Не редактируй вручную — правь шаблон/манифест и запускай `sync`:

- блок `<!-- agents:footer:start ... --> … <!-- agents:footer:end -->` в каждом документе —
  дата/база проверки и ссылка на правила;
- таблица между `<!-- docs:index:start -->` и `<!-- docs:index:end -->` в `docs/README.md`.

Футеры и индекс проверка сравнивает с манифестом. Файлов-указателей в этой установке нет
(`[[pointer]]` не задан), поэтому `docs/templates/` не нужен.

## Добавление, переименование, удаление документов

**Добавление:** файл → `[[doc]]` в манифест (`sources`, `sections`, `verified`) → `sync` →
ссылки → `check`.

**Переименование:** обнови `path` в манифесте и все ссылки (проверит `check`), запусти `sync`.

**Удаление:** удали файл, запись манифеста и входящие ссылки; причину зафиксируй в ADR/handoff.
ADR не удаляются — только помечаются `Superseded`.

## Обновление doc-system

Версия пакета записана в `[meta] system_version`. Обновление runtime и интеграций — из каталога
пакета:

```bash
python3 <path-to-doc-system>/bin/init.py --upgrade <project>
```

Документы и `AGENTS.md` при обновлении не перезаписываются.

## Сбои и восстановление

| Симптом | Что делать |
| --- | --- |
| футер / индекс устарел | `sync` |
| «документ не зарегистрирован» | добавить `[[doc]]` или удалить лишний файл |
| «ссылка ведёт в никуда» / «якорь не найден» | исправить путь/заголовок |
| «нет обязательного раздела» | вернуть раздел или осознанно обновить `sections` |
| «база проверки не зафиксирована» | один раз `touch --all` |
| «коммит проверки не найден» | история переписана: перечитать и `touch` |
| версия runtime не совпадает с манифестом | `init.py --upgrade <project>` |
| `tomllib` не найден | Python < 3.11 |
